# Animal World Minya

70. BRAND IDENTITY — ANIMAL WORLD

The official brand name is:

عالم الحيوان

English brand name:

Animal World

The website represents a professional veterinary clinic and pet-care e-commerce store based in:

Minya, Egypt — المنيا، مصر

The brand should have a strong local identity while maintaining a modern, premium, trustworthy appearance.

Use the Arabic name "عالم الحيوان" as the primary brand name in the main logo and brand identity.

The English name "Animal World" can be used as a secondary brand expression where appropriate.

Do NOT invent a different business name.

Do NOT use placeholder business names such as "PetCare", "Pet Clinic", "Happy Pets", etc.

The brand identity should consistently communicate:

عالم الحيوان
Animal World
Veterinary Care • Pet Products • Pet Wellness

71. LOCATION & LOCAL BRAND PRESENCE

The physical business is located in:

Minya, Egypt

Use this location naturally throughout the website.

Examples:

"Trusted Pet Care in Minya"

"Veterinary Care & Pet Products in Minya, Egypt"

"عالم الحيوان — المنيا، مصر"

Include a dedicated Contact / Location section showing:

Minya, Egypt

Address placeholder that can be edited from the Admin Dashboard

Phone number placeholder

WhatsApp placeholder

Working hours

Google Maps location placeholder

IMPORTANT:

All location information must be editable from the Admin Dashboard.

Do not hard-code the address.

72. OFFICIAL BRAND MASCOTS

The brand has two main characters:

The Animal World Dog
and
The Animal World Cat

These two characters are central to the brand identity.

They should appear consistently throughout the website.

The attached visual reference represents the general personality and playful spirit desired for the mascots.

IMPORTANT:

Use the reference as inspiration for the characters' personality, expressions, and playful relationship.

Do NOT simply copy the original artwork.

Redesign the characters into a modern, polished, premium 2D cartoon illustration style suitable for a professional veterinary and e-commerce brand.

The two characters should feel like best friends and part of the same brand family.

Create visual interactions between them.

Examples:

Walking together

Looking at a product

Celebrating an order together

Helping each other

Playing together

Sitting next to the brand logo

Their relationship should communicate:

"We take care of every pet."

76. MODERN REDESIGN OF THE REFERENCE CHARACTERS

The reference characters should NOT be reproduced with the same rough drawing style.

Upgrade them into:

Modern 2D illustration

Clean vector-like shapes

Smooth curves

Professional proportions

Expressive faces

Consistent outlines

High-quality digital illustration

Premium color treatment

Soft shadows

Subtle depth

Modern animation-ready design

Keep them recognizable as the same conceptual characters.

The final mascots should feel like they belong to a modern Egyptian pet-care brand.

77. BRAND MASCOT RULE

The exact same Dog and Cat designs must be reused throughout the entire website.

Never generate a completely different dog or cat for another page.

Only change:

Pose

Expression

Action

Accessories

Animation

Keep consistent:

Face

Eyes

Body proportions

Colors

Illustration style

Character identity

The mascots should become recognizable brand assets.

81. BRAND PERSONALITY

The final brand personality should be:

Professional + Friendly + Playful + Trustworthy + Modern

The website should NOT feel:

Too childish

Too clinical

Too corporate

Too generic

Too cartoon-heavy

The mascots should add emotion and personality without compromising professional veterinary credibility.

82. FINAL BRAND STATEMENT

The website should communicate this idea immediately:

عالم الحيوان — مكان واحد لكل ما يحتاجه حيوانك الأليف.

A trusted veterinary clinic and modern pet store in Minya, Egypt.

The brand combines:

Veterinary Expertise + Pet Products + Pet Wellness + Friendly Experience
